# Cruise Companion

A phone web app for planning and playing on a cruise: day-by-day plans and reservations, a slots points contest with per-player bankrolls, a scavenger hunt bingo card, trivia, a postcard camera with hats and island backdrops, and trip lists (packing, budget, food, crew, deck spots).

- Lives in `web/`; pushing to `main` publishes it to GitHub Pages.
- Everything you enter stays in your phone's browser. Share with a travel partner by sending a data file (+ › Share).
- On first open it asks for your names and your cruise.

See `web/README.md` for details.
